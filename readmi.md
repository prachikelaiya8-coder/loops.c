C Language – Do While Loop Programs
This repository contains simple C programs created while learning do-while loops, loops, and basic number operations.
Programs Included
skiper.c – Prints characters by skipping 3 characters each time.
counter.c – Counts the total number of digits in a given number.
addition.c – Finds the first and last digit of a number and calculates their sum.
Topics Used
C Language Basics
do-while Loop
while Loop
Variables
printf() and scanf()
Arithmetic Operators
Basic Number Logic
